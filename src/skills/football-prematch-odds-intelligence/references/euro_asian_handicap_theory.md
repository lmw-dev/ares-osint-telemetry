# 欧亚双盘时间研判核心理论指引 (Ares V2.1 规范版)

本指引是 `football-prematch-odds-intelligence` 技能的核心研判算法与理论底座。AI 扮演赔率分析引擎时，必须严格参照本指引中的**量化触发阈值**来自动提取 `market_move` 信号，并生成符合 Ares 量化系统直接读取的 `market_tags` 与 `risk_tags` 标签组。

---

## 1. 欧亚盘折算与水位区间

### 1.1 折算对照基准表
| 欧赔胜赔区间 | 亚盘让球参考线 | 典型折水配置 | 说明 |
| :--- | :--- | :--- | :--- |
| **> 2.30** | `0 (平手)` | 中低水 - 中高水 | 均势，无明显让球优势 |
| **2.11 - 2.30** | `0/0.25 (平/半)` | 主队超高水 / 贴水 | 主队微弱战意或主场偏向 |
| **1.91 - 2.10** | `0/0.25 (平/半)` | 主队低水 - 中水 | 主队常规主场优势 |
| **1.86 - 1.90** | `-0.5 (半球)` | 主队高水 - 超高水 | 主队独赢方可赢盘的生死线 |
| **1.66 - 1.85** | `-0.5 (半球)` | 主队低水 - 中水 | 主队实力优势明确打出生死盘 |
| **1.56 - 1.65** | `-0.75 (半一)` | 主队中高水 - 高水 | 主队赢一球赢半，两球全赢 |
| **1.41 - 1.55** | `-0.75 (半一)` | 主队低水 - 中低水 | 主队战意或基本面压倒性占优 |
| **1.31 - 1.40** | `-1 (一球)` | 主队中水 - 高水 | 主队赢一球走水，二球全赢 |
| **1.21 - 1.30** | `-1.25 (一/球半)`| 主队中水 - 高水 | 强弱极其悬殊 |
| **< 1.20** | `-1.5 及以上` | 根据即时折水动态匹配 | 绝对实力碾压 |

### 1.2 水位高低档量化区间
* **超低水**：`< 0.80` （极度防范，赔付控制严格）
* **低水**：`0.80 - 0.88` （受资金支持或风控下调）
* **中水**：`0.89 - 0.95` （筹码均势点，无明显倾向）
* **高水**：`0.96 - 1.02` （阻碍资金，转嫁赔付压力）
* **超高水**：`> 1.02` （庄家对该方极度怀疑，打出面临过载赔付风险）

## 2. 自动化市场打标算法 (Market Tagging Logic)

大模型在处理数据时，必须按照以下**量化规则**，自动将标签归档至 `market_tags` 数组中。

### 2.1 欧赔变动打标 (`market_tags`)
* **`HOME_EURO_STRENGTHENED`** (主胜强化)  
  *触发条件*：`euro_avg.current.home` 相比 `euro_avg.initial.home` 下降 **0.05** 或以上。
* **`AWAY_EURO_STRENGTHENED`** (客胜强化)  
  *触发条件*：`euro_avg.current.away` 相比 `euro_avg.initial.away` 下降 **0.08** 或以上。
* **`DRAW_EURO_COMPRESSED`** (平赔压低防守)  
  *触发条件*：`euro_avg.current.draw` 相比 `euro_avg.initial.draw` 下降 **0.15** 或以上（庄家防平意图明显）。

### 2.2 亚盘变动打标 (`market_tags`)
* **`HOME_HANDICAP_WATER_SUPPORT`** (主队亚盘低水支撑)  
  *触发条件*：即时亚盘盘口维持与初盘一致，但主队平均水位 `favorite_water_current` 相比初盘 `favorite_water_initial` 下降 **0.08** 或以上，且即时水落在**低水/超低水区间**（< 0.88）。
* **`AWAY_HANDICAP_WATER_SUPPORT`** (客队亚盘低水支撑)  
  *触发条件*：即时亚盘盘口维持与初盘一致，但客队平均水位相比初盘下降 **0.08** 或以上，且落在 < 0.88 水位区间。
* **`EURO_ASIAN_ALIGNED`** (欧亚双盘同向对齐)  
  *触发条件*：`euro_signal` 表现为主队强化/客队强化，且对应的亚盘盘口 `asian_signal` 表现为升盘/水位下调，两边方向**完全一致**。
* **`LOW_TO_MEDIUM_HANDICAP_FAVORITE`** (中低让让步盘)  
  *触发条件*：即时让球线在 `0` 到 `-0.5` 之间（均势盘到生死半球盘之间）。
* **`DEEP_HANDICAP_FAVORITE`** (深让步盘)  
  *触发条件*：即时让球线大于等于 `-0.75`。

### 2.3 大小球变动打标 (`market_tags`)
* **`OVER_WATER_COMPRESSED`** (大球水位压缩)  
  *触发条件*：即时大小球盘口线维持一致，但大球水位较初盘下降 **0.10** 或以上，或者即时大球水位落在**超低水区间**（< 0.80）。
* **`UNDER_WATER_COMPRESSED`** (小球水位压缩)  
  *触发条件*：即时大小球盘口线维持一致，但小球水位较初盘下降 **0.10** 或以上。

## 3. 自动化风险打标算法 (Risk Tagging Logic)

一旦触发以下异常，AI 分析引擎必须自动将标签归档至 `risk_tags` 数组中。

* **`EURO_ASIAN_SPLIT`** (欧亚大裂痕 - 极度高危冷门信号)  
  *触发条件*：以下情况之一发生：
  1. 欧赔主胜走低（降幅 > 0.05），但亚盘主队贴水反而上升（涨幅 > 0.06），或者发生了亚盘退盘（如 -0.75 退至 -0.5）。
  2. 欧赔主胜走高，但亚盘主队贴水异常暴降。
* **`FAVORITE_RETREAT`** (让步盘口退缩)  
  *触发条件*：`handicap_current` 让步深度弱于 `handicap_initial`（例如从初盘 `-0.5` 退让至即时 `-0.25`）。
* **`FAVORITE_NEAR_UPPER_BOUND`** (让球贴水濒临超载上限)  
  *触发条件*：即时让球强队贴水 `favorite_water_current` 上涨至 **1.03 或以上**（高水/超高水区间，赔付风险大增）。
* **`DRAW_COMPRESSED`** (平局市场异常压低)  
  *触发条件*：八大公司中有三家或以上公司的即时平赔降幅达到 0.20 或以上，且即时平赔数值低于 **3.10**（异常防平信号）。
